## Запуск

```
php -S localhost:8000 -t public
```

Открыть http://localhost:8000

## Тесты

```
php tests/run_tests.php
```

## Структура

- `public/index.php` — HTTP-цикл и отображение
- `src/validation.php` — извлечение, нормализация, валидация, h()
- `tests/run_tests.php` — тесты функций

## Правила

| Поле | Правило |
|---|---|
| ФИО | обязательно, 3–100 символов, trim |
| E-mail | обязателен, FILTER_VALIDATE_EMAIL, trim |
| Группа, дисциплина, формат | allow-list, строгое сравнение |
| Бизнес-правило | «Лабораторный практикум» только очно |
| Согласие | обязательно (значение '1') |
